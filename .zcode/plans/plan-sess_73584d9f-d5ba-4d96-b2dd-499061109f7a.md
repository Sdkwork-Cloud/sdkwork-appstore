# PC 版功能完善计划（对齐 PRD P0/P1 + 修复占位）

## 现状结论（探索所得）

已实现 15 个路由、大部分读取类功能已接真实 SDK。缺失/占位：
- **PRD 页面缺失**：`/library`、`/wishlist`、`/category/:id`、`/collection/:id`、`/events/:id`、`/publisher*`（Publisher Console 完全缺失）
- **未接线**：wishlist SDK（已生成未用）、搜索历史、首页真实编辑流（Discover 硬编码 app id）、安装流程（localStorage 模拟，真实端口闲置）、下载凭证
- **占位报错**：Admin Monitor 全占位；Console API 密钥/安全策略卡片崩溃消失；MCP/Plugin/Skill 按钮 throw 无错误 UI
- **死代码**：`src/data/mock.ts`、`src/data/aiStoreMock.ts`（无引用）

按推荐范围全量实施：消费者端页面 + 数据接线 + Publisher Console 完整版 + Admin 真实接线（优雅降级）+ 安装接后端。

## 一、服务层扩展（pc-core 端口 + bootstrap 实现）

**A1. `packages/sdkwork-appstore-pc-core/src/services/api.ts`（AppStoreService 端口）新增**：
- 收藏：`getWishlist()` / `addToWishlist(id)` / `removeFromWishlist(id)` → wishlist facade
- 分类/合集/活动：`getCategoryDetail(id)`（categories.retrieve）、`getCollectionDetail(id)`（collections.retrieve）、`getEvents()` / `getEventDetail(id)`（events.list/retrieve）
- 搜索历史：`getSearchHistory()` / `saveSearchTerm(term)` / `clearSearchHistory()`（search.history facade）
- 库：`getInstalledApps()`（library.listItems + listings 合并，复用现有 read* helper）
- 首页：`listRecentlyUpdated()`（recentlyUpdated.list）
- 新增类型：`EventItem`（id/title/subtitle/banner/startAt/endAt/appIds/status）、`WishlistItem`

**A2. `src/bootstrap/appStore.ts`**：实现上述方法（沿用 mapListingSummary/readPageItems/readString 模式，401/未登录 catch 降级返回空）。

**A3. `src/bootstrap/install.ts` + `src/providers/InstallProvider.tsx`**：安装/卸载接真实后端（`library.install/uninstall`），保留本地进度模拟与「打开」沙盒提示；初始化时从 `getInstalledAppIds()` 加载（失败回退 localStorage 种子）；未登录 401 优雅降级。

**A4. `packages/sdkwork-appstore-pc-core/src/services/console.ts`（ConsoleService 端口）扩展 Publisher 能力**：
- `getPublisherProfile()` / `registerPublisher(data)` / `submitVerification(data)`（publishers.getMe/create/submitVerification）
- `getListingById(id)` / `updateListing(id, patch)`（listings.get/update）
- `getReleases(listingId)` / `createRelease(listingId, data)` / `updateReleaseRollout(releaseId, percent)`（releases 全链路）
- `submitListingForReview(listingId, notes)`（listings.createSubmission）
- `listMembers(id)` / `inviteMember(id, email, role)`
- 新增类型：`PublisherProfile`、`ReleaseItem`、`ManagedAppDetail`

**A5. `packages/sdkwork-appstore-pc-admin-core/src/services/adminMonitor.ts`**：
- `getMetrics()` 真实映射 backend `analytics.operator.dashboard.retrieve()`（大盘统计：应用数/评论数/待审数等，替换抛错）
- 新增 `getModerationQueue()` / `decideReview(reviewId, decision, reason)`（backend moderation.queue.list + decisions.create）
- `getClusterNodes`/`restartNode`/`getSystemAuditLogs` 保持 fail-closed（后端确实未提供），页面改为优雅降级展示

## 风险与约定

- IAM `appstore.*` 权限可能未注册 → publisher/admin 接口可能 403：所有新页面必须有错误/降级态，不崩溃
- 写操作（收藏/安装/评论）未登录 401：提示登录而非报错
- 不改 generated SDK、不手改 schema；仅经 composed facade 与端口扩展
- 域外能力（API 密钥/安全策略/MCP 添加/Plugin 沙盒/Skill 发布）后端未暴露，保持 fail-closed 但修复错误 UI
